## About

This is a temporary "coming soon" website for **Outfox Energía**. It will stay live while the company setup and processes in Spain are being completed, then be replaced by the full website.

The page introduces the brand, explains what customers can expect, and features the Outfox fox mascot in a Spanish village scene.

### Features

- Spanish and English versions with an ES / EN language toggle
- Hero section with brand messaging and three key benefits (Menos factura · Más control · Cero líos)
- Animated Outfox fox mascot
- Custom illustrated background of a Spanish village at dusk
- Responsive layout for desktop, tablet and mobile

## Getting started

```bash
# 1. Clone the repository
git clone https://github.com/<your-org>/<repo-name>.git
cd <repo-name>

# 2. Install dependencies
npm install

# 3. Start the local development server
npm run dev
```

> Check `package.json` for the exact scripts and local port.

### Build for production

```bash
npm run build
```
